Try a home value estimate

The hedonic model from the repo, running in your browser. It was fitted to Ames, Iowa sales (2006 to 2010), so values are Ames-scale and 2010 dollars.

Not an appraisal. A USPAP-compliant appraisal requires a licensed or certified appraiser. This page is an analysis and education tool.

    When to trust it

    Trust it a little when the home looks ordinary for the area. Do not lean on it for unusual homes, new construction, big remodels, or anywhere outside Ames. The full tool adds a gradient-boosted model and a confidence score; run it from the command line.

    Data: Ames, Iowa Assessor's Office sales as published by De Cock (2011), Journal of Statistics Education 19(3). The data is not stored in this repo. Only fitted coefficients are used here. Source and model card.
